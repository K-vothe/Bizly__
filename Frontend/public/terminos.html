Términos de uso — Bizly

Versión 1.0 · Documento académico de referencia

Bizly es un sistema de gestión de ventas, inventario y clientes. Cada usuario es responsable de mantener sus credenciales en reserva y de utilizar las funciones disponibles según el rol asignado.

Uso autorizado

No está permitido intentar acceder a cuentas ajenas, evadir controles de permisos, alterar registros mediante mecanismos no autorizados o utilizar el sistema para almacenar contenido ilícito.

Exactitud de la información

Los usuarios deben procurar que los datos de productos, clientes y operaciones registrados en Bizly sean correctos. Las anulaciones y cambios relevantes quedan sujetos a trazabilidad.

Disponibilidad

La disponibilidad del servicio depende de la infraestructura donde se despliegue la aplicación, la base de datos y los servicios de correo configurados.

Cuenta y seguridad

Bizly puede bloquear temporalmente intentos reiterados de acceso incorrecto y permite revocar sesiones activas. La eliminación de cuenta se implementa como desactivación y anonimización cuando sea necesario conservar registros operativos.

Nota: Este documento es una base para fines académicos y debe adaptarse antes de un uso comercial real.
